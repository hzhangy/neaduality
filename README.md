
# N.E.A. Framework Papers: Topological Genesis of Dimensions and Unification of Physics

This repository contains the source code, numerical experiment scripts, and generated figures for two companion papers:

- **Paper V**: `paper/paper_v.tex` — *Topological Genesis of Dimensions: Forces as Dual Anchors of Dimensionality (A Heuristic 0-1-2-3-4 Zig-zag Ladder with Preliminary Numerical Support)*
- **Paper VI**: `paper/paper_vi.tex` — *N.E.A. Physics: Unification of Relativity and Quantum Mechanics under Bandwidth Constraints (The Computational Origin of SR, Entanglement, and the Equivalence Principle)*

Precompiled PDFs are also available: `paper/paper_v.pdf` and `paper/paper_vi.pdf`.

Together, the two papers present the unified physical picture of the N.E.A. (Network Emergent Architecture) framework: fundamental forces, spacetime, relativity, and quantum mechanics are all uniquely determined by network evolution under finite bandwidth constraints.

## Requirements

- Python 3.9+
- numpy, scipy, matplotlib

Install dependencies:
```bash
pip install numpy scipy matplotlib
Running Numerical Experiments
Enter the code/ directory and run the scripts. Each script generates figures and saves them to the paper/figures/ folder (some scripts may require manually adding plt.savefig; the locations are indicated in the code comments).

Example:

bash
cd code
python weak_force_exp.py
python exp1_em_scaling_10000.py   # This one is slower; you may run only part of the N range
...
Compiling the Papers
Enter the paper/ directory and compile with pdflatex:

bash
cd paper
pdflatex paper_v.tex
pdflatex paper_vi.tex
(If you use BibTeX for references, run bibtex as well.)
